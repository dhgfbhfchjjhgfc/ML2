## Результат в двух словах

Выбран датасет транзакций европейских держателей карт с экстремальным дисбалансом классов (мошеннических операций всего 0.17%). Обоснован отказ от метрики ROC-AUC в пользу PR-AUC (Precision-Recall Area Under Curve), так как при сильном дисбалансе ROC-AUC дает обманчиво высокий результат. Установлен числовой порог успеха PR-AUC >= 0.80.

## Как запустить

```bash
uv sync                                   # зависимости (Python 3.14 uv поставит сам)
uv sync --group torch --group notebooks   # PyTorch (CPU) и marimo — для этапов 2–3
uv run python -m mlproject.data           # этап 2: очистка и разбиение
uv run python -m mlproject.train          # этап 3: модели, Optuna, MLflow
uv run python -m mlproject.evaluate       # этап 4: интервалы, калибровка, SHAP, ошибки
uv run uvicorn mlproject.api:app --port 8000   # этап 5: сервис
uv run python -m mlproject.monitor        # этап 6: отчёт о дрейфе
uv run pytest                             # все тесты
uv run python -m grader all               # автопроверка
```

## Этап 1. Постановка задачи

Сформулирована бизнес-задача антифрод-системы для карточных платежей. Выбран датасет транзакций европейских держателей карт с экстремальным дисбалансом классов (мошеннических операций всего 0.17%). Обоснован отказ от метрики ROC-AUC в пользу PR-AUC (Precision-Recall Area Under Curve), так как при сильном дисбалансе ROC-AUC дает обманчиво высокий результат. Установлен числовой порог успеха PR-AUC >= 0.80.
