# Data Card: Credit Card Fraud Detection (OpenML ID 1597)

## Источник
- Ссылка: https://www.openml.org/search?type=data&id=1597 (зеркало оригинального датасета ULB Machine Learning Group).
- Загрузка сохраняет датасет в `data/raw/creditcard.csv` (папка data/raw/ добавлена в .gitignore).

## Лицензия
- Лицензия: Open Database License (ODbL) / Public Domain. Разрешено учебное и исследовательское применение с указанием авторства исследовательской группы ULB.

## Состав данных
- Объем: 284 807 транзакций.
- Колонки: 30 признаков (`V1`–`V28`, `Amount`, целевая `Class`).
- Дисбаланс: 492 мошеннические транзакции (0.172%).

## Персональные данные
Датасет полностью анонимизирован. Исходные атрибуты банковских карт и реквизиты преобразованы методом главных компонент (PCA). Признак `Amount` не содержит персональных идентификаторов (ФИО, телефоны и номера счетов отсутствуют). Требования 152-ФЗ соблюдены.

## Очистка и разбиение
Пропущенные значения отсутствуют (0% NaN). Выбрана стратегия стратифицированного разбиения (`stratified`), сохраняющая долю мошеннических операций в train (70%), val (15%) и test (15%).

## Известные проблемы
Экстремальный дисбаланс классов (1:578). Большинство легитимных транзакций имеют малые суммы (медиана 22$), однако мошеннические транзакции обладают специфическими аномалиями в компонентах V14, V10, V12.
